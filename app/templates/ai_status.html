How to switch it on

Create a free API key at console.groq.com/keys — no credit card required. Then, in the same terminal you start the app from: 

$env:GROQ_API_KEY="gsk_your_key_here"
python run.py

That sets the key for the current terminal only. To set it permanently on Windows: 

[System.Environment]::SetEnvironmentVariable("GROQ_API_KEY", "gsk_your_key_here", "User")

Then close and reopen PowerShell so the variable is picked up.

Switching provider

Groq is the default because its free tier needs no credit card. To use Google Gemini instead (requires billing enabled on a Google Cloud project): 

$env:AI_PROVIDER="gemini"
$env:GEMINI_API_KEY="your_key_here"

You can also override the model with GROQ_MODEL or GEMINI_MODEL if a provider retires the default one.
